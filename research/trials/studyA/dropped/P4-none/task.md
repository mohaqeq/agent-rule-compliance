# Clean up tags when a gift card is deleted

Staff delete gift cards from the dashboard, one at a time or in bulk. Gift cards carry tags for campaigns
and reporting, and the tag list keeps growing with tags that no card uses any more. Staff find the
list cluttered and the tag filter full of dead entries.

When a gift card is deleted, also delete the tags it carried that no other gift card uses. Tags that
are still on another gift card must stay, and so must tags that were already unused before. This should
work the same whether the gift card is deleted on its own or as part of a bulk delete.
